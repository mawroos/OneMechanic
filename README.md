# OneMechanic

Professional mobile car service website - bringing expert auto repair to your home!

## About

OneMechanic is a single-page website template for mobile car service businesses. This modern, responsive website showcases professional auto repair services delivered directly to customers' homes or offices.

## Features

- **Responsive Design**: Built with Bootstrap 5 for optimal viewing on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Service Showcase**: Highlighted services including diagnostics, engine servicing, tire replacement, and oil changes
- **Booking Form**: Easy-to-use booking form for scheduling services
- **Testimonials**: Customer testimonials carousel
- **Contact Section**: Contact form and map integration
- **Mobile-First**: Optimized for mobile viewing

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- Owl Carousel
- WOW.js animations
- Font Awesome icons

## GitHub Pages

## Customization

To customize this template for your business:

1. Update contact information in `index.html`
2. Replace placeholder images in the `img/` folder with your own photos
3. Modify services, pricing, and content as needed
4. Update social media links in the footer
